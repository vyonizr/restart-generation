# Triage labels

The skills speak in terms of five canonical triage roles. The following table maps those roles to the label strings that this repository's issue tracker uses:

| Label in mattpocock/skills | Label in our tracker | Meaning                                                   |
| -------------------------- | -------------------- | --------------------------------------------------------- |
| `needs-triage`             | `needs-triage`       | Maintainer needs to evaluate this issue                   |
| `needs-info`               | `needs-info`         | Waiting on reporter for more information                  |
| `ready-for-agent`          | `ready-for-agent`    | Fully specified, ready for an agent to work on unattended |
| `ready-for-human`          | `ready-for-human`    | Needs a person to implement it                            |
| `wontfix`                  | `wontfix`            | Won't be worked on                                        |

When a skill mentions a role (for example, "apply the AFK-ready triage label"), use the corresponding label string from this table.

To use different labels, edit the "Label in our tracker" column.
